# Machine Learning TTL Assignments

This repository contains implementations of **Machine Learning TTL assignments** completed using **Python** and **Google Colab**. The assignments cover core machine learning techniques, deep learning models, computer vision, natural language processing, feature interpretation, and a basic MLOps workflow.

## Assignments Included

| Sr. No. | Assignment                                   |
| ------- | -------------------------------------------- |
| 1       | **ML Model for Car Mileage Estimation**      |
| 2       | **Simulated Driving Agent Behavior**         |
| 3       | **Data Cleaning & Preprocessing Techniques** |
| 4       | **Vehicle Price Prediction**                 |
| 5       | **Predictive Maintenance from Sensor Logs**  |
| 6       | **Traffic Sign Classification using CNN**    |
| 7       | **Pedestrian Detection using OpenCV**        |
| 8       | **Sentiment Analysis using LSTM**            |
| 9       | **Feature Importance Visualization**         |
| 10      | **MLOps Workflow Simulation**                |

## Technologies Used

* **Programming Language:** Python
* **Development Environment:** Google Colab / Jupyter Notebook

  * NumPy

  * MLflow

## Repository Structure

Each assignment is available as a separate notebook and includes:

* Objective and implementation
* Dataset generation or preprocessing
* Model training and evaluation
* Visualizations and output results

This repository serves as a collection of practical implementations covering different machine learning concepts and workflows.
